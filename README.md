# NOL 예매 타이머

서버 시각 기준 카운트다운과 알림으로, 예매 오픈 순간을 사용자가 직접 정확하게 누를 수 있게 돕는 단일 페이지입니다.
자동 클릭이나 반복 요청은 하지 않습니다.

## 접속

- 호스팅: https://tkdals69.github.io/nol-ticket-timer/
- 시간 소스: timeapi.io UTC 표준시 (5회 샘플, 최단 RTT)

## NOL 서버 시각으로 동기화하려면 (선택)

PC 에서 로컬 프록시를 띄우면 호스팅 페이지가 NOL 서버 시각을 우선 시도합니다 (브라우저 정책에 따라 차단될 수 있으며, 그 경우 timeapi.io 로 자동 폴백합니다. 두 시각의 차이는 20ms 이내로 측정됨).

```
python server.py
```

`http://127.0.0.1:8787` 로 직접 접속해도 같은 페이지가 뜹니다.

## 사용 순서

1. 페이지를 열고 "알림 소리 테스트" 를 한 번 눌러 소리를 켠다.
2. NOL 상품 페이지는 별도 창에 열고 로그인해 둔다.
3. 오픈 5분 전 "서버 시간 동기화" 를 다시 누른다.
4. 알림(T−60 / T−10~1 / T−0)에 맞춰 직접 클릭한다.
